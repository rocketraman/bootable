PostgresqlConfig

data class PostgresqlConfig(val host: String = "localhost", val port: Int = 5432, val database: String, val username: String? = null, val password: Masked? = null, val currentSchema: String? = null, val applicationName: String? = null, val sslMode: PostgresqlSslMode? = null, val connectTimeout: Duration? = null, val socketTimeout: Duration? = null, val reWriteBatchedInserts: Boolean? = null) : JdbcConfig

A strongly typed JdbcConfig for a PostgreSQL database, connected to with the PostgreSQL JDBC driver, which this module brings in. It brings Flyway's PostgreSQL database module too, for boot-db-flyway.

Decoded from the db.jdbc config section:

db {
  jdbc {
    host = db.example.com
    database = app
    username = app
    password = ${?DB_PASSWORD}
    sslMode = VERIFY_FULL
  }
}
Content copied to clipboard

The settings other than the address and credentials are passed to the driver as connection properties. Those left null keep the driver's default. For a server address this can't express, such as several hosts for failover, use JdbcGenericConfig with a JDBC URL instead.
