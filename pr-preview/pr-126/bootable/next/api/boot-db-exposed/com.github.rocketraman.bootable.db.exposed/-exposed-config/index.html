ExposedConfig

data class ExposedConfig(val defaultIsolationLevel: TransactionIsolation? = null, val defaultReadOnly: Boolean? = null, val defaultMaxAttempts: Int? = null, val defaultMinRetryDelay: Duration? = null, val defaultMaxRetryDelay: Duration? = null, val defaultQueryTimeout: Duration? = null, val defaultFetchSize: Int? = null, val warnLongQueriesDuration: Duration? = null, val useNestedTransactions: Boolean? = null, val schemaVerification: SchemaVerification = SchemaVerification.FAIL)

Settings for the Exposed org.jetbrains.exposed.v1.jdbc.Database. Every field but schemaVerification is optional; an unset field keeps Exposed's default. They apply to this Database only, as its DatabaseConfig, and an individual transaction can still override them.

Decoded from the db.exposed config section:

db {
  jdbc { ... }
  exposed {
    defaultIsolationLevel = READ_COMMITTED
    warnLongQueriesDuration = 2s
  }
}

Exposed logs every SQL statement at DEBUG on its Exposed logger, so turn SQL logging on and off in the logging config. For an Exposed setting not listed here, such as a custom SQL logger or an explicit dialect, use an ExposedConfigCustomizer.
