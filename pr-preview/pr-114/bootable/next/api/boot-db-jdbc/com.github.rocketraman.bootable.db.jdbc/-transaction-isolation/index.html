TransactionIsolation

enum TransactionIsolation : Enum<TransactionIsolation>

The JDBC transaction isolation levels, as Connection's TRANSACTION_* constants, for typed config: e.g. a pool's default for new connections, or a database library's default for new transactions.

Not every database supports every level: SQLite, for one, supports only READ_UNCOMMITTED and SERIALIZABLE.
