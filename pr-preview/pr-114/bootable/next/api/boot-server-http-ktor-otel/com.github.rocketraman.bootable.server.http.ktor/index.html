KtorTelemetry

class KtorTelemetry(val openTelemetry: OpenTelemetry, snapshotProviders: Set<MetricsSnapshotProvider> = emptySet(), val config: KtorTelemetryConfig = KtorTelemetryConfig(), customizer: KtorServerTelemetryCustomizer = KtorServerTelemetryCustomizer { })

A Ktor server's telemetry: OpenTelemetry's Ktor server instrumentation, which traces every request (continuing the caller's trace when the request carries one) and records the standard HTTP server metrics, such as http.server.request.duration, and the metrics scrape route for a pulled backend, such as Prometheus, served by snapshotProviders.

MetricsKtorService
Link copied to clipboard
class MetricsKtorService<TEngine : ApplicationEngine, TConfiguration : ApplicationEngine.Configuration>(hostPort: HostPort, engineFactory: ApplicationEngineFactory<TEngine, TConfiguration>, snapshotProvider: MetricsSnapshotProvider, path: String = KtorTelemetryConfig.DEFAULT_PATH, name: String = "metrics") : KtorService<TEngine, TConfiguration>

A listener that serves only snapshotProvider's metrics, at path, on a port of its own: e.g. a scrape port reachable only from inside the cluster, next to a public application server. It isn't traced. Like any KtorService, it starts last and stops first, so a scrape in flight at shutdown is still answered.

An OpenTelemetryCustomizer that records no trace for the health probes served on the application's server by KtorHealth, which the platform's probes would otherwise fill the traces with.
