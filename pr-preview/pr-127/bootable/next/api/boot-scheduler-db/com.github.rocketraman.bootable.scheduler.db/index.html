DbSchedulerService
Link copied to clipboard
class DbSchedulerService(dataSource: DataSource, config: DbSchedulerConfig = DbSchedulerConfig(), tasks: Collection<Task<*>> = emptyList(), customizer: DbSchedulerCustomizer = DbSchedulerCustomizer { }, serializer: Serializer = KotlinxSerializationTaskDataSerializer(), clock: Clock = Clock.System, jdbcUrl: String? = null) : AppService

Runs db-scheduler's Scheduler over the application's DataSource, usually the pool of boot-db-jdbc's JdbcDataSourceService: persistent tasks, recurring and one-time, that survive restarts, and that run once across all the application's instances, each execution on whichever instance locks its row first. So, unlike boot-periodic's in-process loops, they need no leader election.

dbSchedulerTracing
Link copied to clipboard
fun dbSchedulerTracing(openTelemetry: OpenTelemetry, sample: Sample = Sample.BySampler): DbSchedulerCustomizer

A DbSchedulerCustomizer that traces each execution of a db-scheduler task through openTelemetry, with an ExecutionInterceptor: each execution starts a trace of its own, with a root span named for the task, such as db-scheduler send-reminder, so that the spans within it, such as its JDBC statements, and its log events, belong to it. An execution that fails ends its span with an error status and the exception recorded.
