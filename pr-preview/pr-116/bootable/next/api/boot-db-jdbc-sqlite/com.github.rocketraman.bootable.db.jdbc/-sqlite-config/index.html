SqliteConfig

data class SqliteConfig(val path: String, val journalMode: SqliteJournalMode = SqliteJournalMode.WAL, val foreignKeys: Boolean = true, val busyTimeout: Duration = 5.seconds, val synchronous: SqliteSynchronous? = null, val createDirectories: Boolean = true) : JdbcConfig

A strongly typed JdbcConfig for a SQLite database file, with defaults suited to a pooled server application:

  • journalMode WAL, so readers don't block the writer.

  • foreignKeys on. SQLite ignores foreign key constraints unless this is enabled on each connection.

  • busyTimeout of 5 seconds, so a connection waits for a lock instead of failing immediately with SQLITE_BUSY.

  • A pool of one connection unless the pool's maximumPoolSize is set, since SQLite allows only one writer at a time.

  • createDirectories on, so the database file's directory is created when the application starts.

Decoded from the db.jdbc config section:

db {
  jdbc {
    path = "./app.db"
  }
}

The settings are applied as SQLite pragmas on every connection the pool opens.

val createDirectories: Boolean

Whether to create the directory of path if it doesn't exist, when the application starts. SQLite creates the database file itself, but not its directory. Turn this off where the application should not create directories, so that a missing one fails the start instead.
