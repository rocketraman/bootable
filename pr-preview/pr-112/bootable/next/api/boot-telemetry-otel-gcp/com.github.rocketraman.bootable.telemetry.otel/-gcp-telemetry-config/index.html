authenticate

val authenticate: Boolean?

Whether to authenticate OTLP export with Google's application default credentials. Unset, export is authenticated when it goes to Google, i.e. to a googleapis.com endpoint, and not when it goes to a collector.

detectResource
Link copied to clipboard
val detectResource: Boolean

Whether to describe the application with the resource attributes of the GCP platform it runs on, such as the Cloud Run service and revision, or the GKE cluster, namespace, and pod. Off GCP, nothing is added.

projectId
Link copied to clipboard
val projectId: String?

The project that authenticated export is billed and quota-checked against, sent as x-goog-user-project. Defaults to the credentials' own quota project, then to the project the application runs in.
