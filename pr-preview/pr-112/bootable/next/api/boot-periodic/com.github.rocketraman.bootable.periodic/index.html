periodicTracing
Link copied to clipboard
fun periodicTracing(openTelemetry: OpenTelemetry, sample: Sample = Sample.BySampler): PeriodicRunInterceptor

A PeriodicRunInterceptor that traces each run of a PeriodicAppService through openTelemetry: each run starts a trace of its own, with a root span named for the service, such as periodic notifications, so that the spans within it, such as its JDBC statements, and its log events, belong to it. A run that fails ends its span with an error status and the exception recorded.
