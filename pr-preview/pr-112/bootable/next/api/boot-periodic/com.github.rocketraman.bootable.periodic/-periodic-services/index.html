PeriodicServices

class PeriodicServices(val gate: PeriodicGate = PeriodicGate.Always, val clock: Clock = Clock.System, val interceptors: List<PeriodicRunInterceptor> = emptyList(), val onFailure: PeriodicFailureHandler = PeriodicFailureHandler.Log)

What the application's PeriodicAppServices share: their default gate, clock, interceptors, and failure handler, so that each loop needs only its name, config, and work. The DI flavors bind one, from the application's LeaderElection, Clock, and contributed interceptors:

inBindSet<AppService> {
  add { singleton { instance<PeriodicServices>().create("notifications", instance<NotificationsConfig>().loop) { instance<Notifications>().sendPending() } } }
}
