KtorClientConfig

data class KtorClientConfig(val baseUrl: String? = null, val connectTimeout: Duration? = null, val requestTimeout: Duration? = null, val socketTimeout: Duration? = null, val headers: Map<String, Masked> = emptyMap(), val retry: KtorClientRetryConfig? = null, val tls: KtorClientTlsConfig? = null)

One HTTP client's settings. Every field is optional: unset, a named client takes the default client's setting, and the default client keeps Ktor's, or its engine's.

For a Ktor setting not listed here, such as a plugin, use a KtorClientCustomizer.

baseUrl
Link copied to clipboard
val baseUrl: String?

The URL relative request URLs resolve against, through Ktor's DefaultRequest. End it with a / to keep its last path segment: with https://api.example.com/v1/, a request for users goes to https://api.example.com/v1/users, but with https://api.example.com/v1, to https://api.example.com/users.

val headers: Map<String, Masked>

Headers sent with every request, unless the request sets its own. A named client's are added to the default client's, and replace any of the same name. Masked, since they often carry a token.

val requestTimeout: Duration?

How long a whole request may take, from sending it to receiving the response's body.

retry
Link copied to clipboard
val retry: KtorClientRetryConfig?

Retries of failed requests, through Ktor's HttpRequestRetry. Unset, a request is never retried.

socketTimeout
Link copied to clipboard
val socketTimeout: Duration?

The longest the connection may sit idle, waiting for data, in either direction.

tls
Link copied to clipboard
val tls: KtorClientTlsConfig?

The TLS material: a client certificate to present, for mutual TLS, and the certificates to trust. Unset, the client presents none, and trusts the platform's certificate authorities. A named client takes tls whole, so an empty tls {} turns off a client certificate the default client has.
