KtorClientsConfig

data class KtorClientsConfig(val default: KtorClientConfig = KtorClientConfig(), val named: Map<String, KtorClientConfig> = emptyMap())

The application's HTTP clients: a default one, and any number of named ones, each its own HttpClient with its own connection pool. A named client takes every setting it leaves unset from default, so it only states what differs, such as a base URL, or a client certificate of its own.

Decoded from the http.client config section:

http {
  client {
    default {
      connectTimeout = 5s
      requestTimeout = 30s
      retry { maxRetries = 3 }
    }
    named {
      github {
        baseUrl = "https://api.github.com/"
        headers { Accept = "application/vnd.github+json" }
      }
      partner {
        requestTimeout = 300s
        tls {
          keyStore { base64 = ${PARTNER_KEYSTORE}, password = ${PARTNER_KEYSTORE_PASSWORD} }
        }
      }
    }
  }
}
